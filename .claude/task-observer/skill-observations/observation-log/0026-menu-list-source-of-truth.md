**Issue:** The first list was built from the booking system's internal notes. The user corrected: the email exchange is authoritative. Notes listed arrangements that were not menus (starters + à la carte), and one note differed from the mailed menu (a dish that was never offered).

**Suggested improvement:** When compiling "what was agreed", read the primary record (sent offers + the guest's confirming reply) first; use secondary notes only as a cross-check and report mismatches instead of copying them.

**Principle:** Derived records drift from the source of truth; build summaries from the primary record and treat secondary systems as checks.
